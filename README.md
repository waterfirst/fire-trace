# 산불추적기 · FireTrace Korea

2025년 의성 산불의 확산을 시간축·열점·기상·인구·뉴스 레이어로 읽는 React 시연판이다.

## 현재 범위

- 시간축 재생과 지도 열점 시각화
- 풍속·습도·영향권 인구 지표
- 바람·인구·뉴스 레이어 토글
- GitHub Pages 자동 배포

현재 화면 수치는 **UI 검증용 합성 데이터**다. 실제 경보나 재난 판단에 사용하면 안 된다.

## 실행

```bash
npm install
npm run dev
```

## 실제 데이터 연결 예정

NASA FIRMS, 기상청 ASOS, ERA5, 행안부 주민등록 인구, 산림청 산불통계, 뉴스 API.
